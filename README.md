A Python Tkinter desktop application that tracks real-time cryptocurrency prices using public APIs. Users can:

View current prices of major cryptocurrencies like Bitcoin, Ethereum, and more.

Monitor price changes in real-time (requires internet connection).

Save favorite cryptocurrencies for quick access.

Operate the app offline for saved data, while online updates fetch live market data.

Enjoy a user-friendly dark-themed interface for comfortable viewing.

Technologies Used: Python, Tkinter, Requests, JSON.

Use Case: Perfect for crypto enthusiasts, investors, or anyone who wants to quickly check cryptocurrency prices on their desktop without opening a browser.
